# AOELike

Un jeu de stratégie en temps réel (RTS) open source inspiré d'Age of Empires II et StarCraft, développé avec Godot 4 et jouable directement dans le navigateur.

**Jouer :** [babousoulchild.github.io/AOELike](https://babousoulchild.github.io/AOELike)

---

## Vision

AOELike est un projet communautaire modulaire. Chaque civilisation est un pack indépendant (assets + code + config) que n'importe quel contributeur peut créer et soumettre.

L'objectif est de construire un RTS extensible à l'infini — du médiéval humain à l'extraterrestre, en passant par des peuples animaux ou fantastiques.

## Stack technique

- **Moteur :** Godot 4.3
- **Langage :** GDScript
- **Plateforme :** HTML5 (navigateur) via GitHub Pages
- **Graphismes :** Pixel art isométrique — Aseprite

## Contribuer

- **Code / Game design :** Ouvre une Issue ou une Pull Request
- **Graphismes :** Consulte [CONTRIBUTING_ART.md](CONTRIBUTING_ART.md)

## Développement local

1. Installe [Godot 4.3](https://godotengine.org/download)
2. Clone le repo
3. Ouvre `project.godot` dans Godot
4. Lance avec F5

## Déploiement

Chaque push sur `main` déclenche automatiquement l'export HTML5 et le déploiement sur GitHub Pages via GitHub Actions.
