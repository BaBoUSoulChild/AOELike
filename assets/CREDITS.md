# Crédits assets — Sprint 3 (placeholders)

Ces assets remplacent les losanges colorés du Sprint 2. Ce sont des
placeholders en attendant les packs pixel art dédiés à chaque civilisation
(voir `CONTRIBUTING_ART.md`).

## Terrain — `assets/shared/terrain/`

- `grass_a.png`, `grass_b.png` : extraits du pack **Isometric Landscape** par
  Kenney (www.kenney.nl), licence **CC0 1.0 (Domaine public)**.
  Récupérés via le miroir GitHub CC0 `ETdoFresh/kenney.nl`
  (`isometriclandscape/PNG/landscapeTiles_067.png` et `_075.png`),
  recadrés sur la face supérieure en losange.

## Ressources, bâtiments, unités — `assets/shared/resources/`, `buildings/`, `units/`

- `tree.png`, `gold_rock.png`, `town_center.png`, `villager.png` :
  pixel art généré par script (Pillow), placeholders maison — aucune
  attribution requise. À remplacer par des assets communautaires conformes
  à `CONTRIBUTING_ART.md`.
